# 阿信写词技法深度解析

> 供 `ashin-lyrics` Skill 调用，将抽象的「阿信风格」拆解为可操作的写作模式。

## 1. 主题层

### 1.1 平凡英雄
- 主角永远是普通人：上班族、学生、便利店店员。
- 把日常处境（堵车、加班、暗恋）写成史诗。
- 公式：日常细节 + 宇宙级隐喻。

### 1.2 我们叙事
- 「我」与「你」最终汇成「我们」。
- 主歌写个人困境，副歌升级为群体宣告。

## 2. 结构层

### 2.1 三段式情绪曲线
```
主歌 1 (描述场景，低能量)
→ 主歌 2 (引入矛盾)
→ 预副 (情绪堆叠，旋律抬升)
→ 副歌 (爆发，宣告)
→ Bridge (反转视角 / 升 key)
→ 副歌 Reprise (释放)
```

### 2.2 副歌锚句
- 副歌第一句必须是「金句级」：短、押韵、可独立传唱。
- 例如：「当我和世界不一样」、「我不怕千万人阻挡」、「突然好想你」。

## 3. 修辞层

### 3.1 高频意象库
| 类别 | 词 |
|------|-----|
| 自然 | 星 / 海 / 风 / 雨 / 光 / 夏天 / 黄昏 |
| 空间 | 路 / 桥 / 窗 / 街角 / 房间 |
| 行动 | 拥抱 / 奔跑 / 出发 / 飞 / 等 |
| 时间 | 青春 / 后来 / 那年 / 永远 |

### 3.2 反差句式
- 「世界 + 渺小动作」：让世界毁灭，让我抱你。
- 「巨大形容词 + 卑微名词」：宇宙级的孤单。

### 3.3 闽南语调味
- 偶尔在副歌或 Bridge 嵌入一句闽南语（如《诺亚方舟》《憨人》），强化在地性。

## 4. 韵律层

### 4.1 常用韵脚
- **ang / iang** — 想、上、光、量、忘
- **ai / uai** — 爱、来、海、外、白
- **ou** — 走、留、头、收
- **ong** — 风、空、用、动

### 4.2 节奏
- 主歌多用短句（4-6 字），副歌可拉长至 9-11 字。
- 喜欢在副歌结尾用拖音字（啊、吧、呢）增加歌唱性。

## 5. 反模式（避免）

- ❌ 过度使用网络流行语。
- ❌ 押韵生硬牺牲语义。
- ❌ 副歌堆砌口号无具体画面。
- ❌ 视角混乱（一段同时出现我/你/他/我们但无逻辑）。

## 6. 自检清单

生成歌词后，问自己：
- [ ] 是否有一个可独立传唱的副歌锚句？
- [ ] 主歌是否给出具体场景而不是抽象议论？
- [ ] 韵脚是否自然？
- [ ] 整首歌是否有一条情绪上升曲线？
- [ ] 是否避免了任何与现有五月天歌词雷同的段落？
