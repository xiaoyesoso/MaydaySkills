# ashin-lyrics · 阿信风格歌词生成

> 模仿五月天主唱阿信的创作风格，生成**原创**中文歌词。

## 这个 Skill 能做什么

- 根据你给的主题、情绪、长度，产出三段不同风格的副歌草稿。
- 三种基调可选：`inspirational`（励志）、`melancholic`（忧伤）、`passionate`（热血）。
- 每个草稿都会标注：使用了哪种押韵方式、属于阿信的哪一种写作模式。
- 选定草稿后，可扩写为完整歌词（含主歌、预副、副歌、Bridge 段落标记）。

## 适合什么场景

- 想给乐队 / 班级 / 婚礼写一首「像五月天的歌」。
- 在写故事 / 剧本 / 短视频文案时，需要一段歌词式的旁白。
- 学习如何把日常细节写成「金句副歌」。

## 工作流程

1. 你告诉我：主题（例如「离职」）、基调（例如 melancholic）、长度（例如「整首歌」）。
2. 我从 `references/lyrics-db/` 取参考样本（仅参考风格，不抄歌词）。
3. 输出 3 段不同写法的副歌草稿。
4. 你挑一段，我扩成完整版。

## 注意事项

- ⚠️ **版权**：不会输出任何现有五月天歌曲的歌词全文；如需正版歌词请去授权平台。
- ⚠️ **语言**：风格为中文优化，闽南语 / 英文混搭仅作点缀。
- ⚠️ **原创性**：每段输出都会做去重，避免与已有歌词雷同。
