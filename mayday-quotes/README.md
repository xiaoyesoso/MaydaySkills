# mayday-quotes · 五月天金句生成器

> 把任何生活时刻匹配到五月天金句，或把任何文字改写成五月天的口吻。

## 这个 Skill 能做什么

1. **quote-match 金句匹配** — 描述一个场景（例如「明天要辞职」），返回 3 句最贴合的五月天歌词 + 出处。
2. **style-rewrite 风格改写** — 把你的朋友圈、PPT 标题、信件改写成五月天歌词的味道，三种风格可选：`热血版` / `温柔版` / `黑色幽默版`。
3. **occasion 场景模板** — 20+ 预设场景（毕业、离职、告白、纪念日…）一键调用。

## 适合什么场景

- 想发朋友圈、IG、Threads，但脑子空白。
- 离职信、毕业留言、生日贺卡需要一句加分句。
- 演讲 / PPT 的金句开场或收尾。

```
mayday-quotes/
```

## 输出示例

```
🎵 你的 [离职] 适合：
━━━━━━━━━━━━━━━━━
1. 「当我和世界不一样 那就让我不一样」 ——《倔强》
   ✨ Why: 离开是为了忠于自己。
2. 「突然好想你 你会在哪里」 ——《突然好想你》
   ✨ Why: 给同事的告别更轻盈一些。
3. 「把无聊的日子 折一只飞机」 ——《后青春期的诗》
   ✨ Why: 离职那天的小小仪式感。
```
