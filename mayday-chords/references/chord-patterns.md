# 五月天高频和弦模式数据库

> 供 `mayday-chords` Skill 调用。本文件是模式索引，非完整曲谱。

## 1. 高频进行 (Common Progressions)

| 编号 | 进行 | Roman | 用例 |
|------|------|-------|------|
| P1 | C - G - Am - F | I-V-vi-IV | 五月天最广用的副歌进行（情绪正向） |
| P2 | C - Em - F - G | I-iii-IV-V | 主歌叙事感 |
| P3 | Am - F - C - G | vi-IV-I-V | 副歌温暖向 |
| P4 | F - G - Em - Am | IV-V-iii-vi | 抒情慢歌主歌 |
| P5 | Dm - G - C - Am | ii-V-I-vi | 比较少用的爵士味 |

## 2. 升 Key 范式 (Modulation Patterns)

| 类型 | 描述 | 经典案例 |
|------|------|----------|
| 全音升 key | 副歌后整调升一个全音 | 《倔强》Bridge → 最终副歌 |
| 半音上行 | 在 Bridge 内连续半音上升 | 《你不是真正的快乐》 |
| 副属和弦推进 | V/V 推 V，再回 I | 《温柔》部分段落 |
| 平行小调切换 | I 大调副歌切到 i 小调 Bridge | 《突然好想你》局部 |

## 3. 编曲特征 (Arrangement Tells)

- **主歌**：木吉他 + 贝斯 + 简单鼓 hi-hat。
- **预副**：加入 piano 长音 + 鼓填入。
- **副歌**：双吉他失真 + 全鼓 + 弦乐衬底。
- **Bridge**：通常拆掉鼓只剩钢琴/吉他清音，再用爆鼓 reentry。
- **结尾副歌**：常加 Backing Vocals & 升 key。

## 4. 难度分级 (Learning Roadmap)

- 你不是真正的快乐

## 5. 怪兽编曲哲学（速记）

1. 「主歌克制 → 副歌爆发」是默认结构。
2. 副歌的 hook 经常落在 IV → V → vi 这种「悬而未决」之间。
3. 喜欢用 Bridge 重新定义整首歌的情绪重心。
4. 升 key 不只是炫技，更是「再说一次」的语气强调。

## 6. 与 chord-diagram.py 的衔接

```
   ┌─┬─┬─┬─┬─┐
A  │ │○│ │○│ │   ← 实际为 Am
   ├─┼─┼─┼─┼─┤
```
脚本逻辑见 `../scripts/chord-diagram.py`。
