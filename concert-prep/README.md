# concert-prep · 演唱会备战助手

> 把焦虑的五迷变成战备好的歌迷 — 从 Setlist 预测到场馆攻略一条龙。

## 这个 Skill 能做什么

1. **Setlist 智能预测** — 基于最近场次频率给出预测歌单，并标记 🎤 大合唱 / ⚡ 跳跃 / 🕯️ 灯海 / 🎸 吉他 solo。
2. **应援指南** — 安可节奏、灯海时刻、纸飞机段落、巡演专属传统。
3. **场馆攻略** — 交通 / 入场 / 散场 / 寄物 / 厕所 / 周边餐饮。
4. **必带清单** — 灯棒、行动电源、喉糖、票面截图、雨具、保暖外套等。
5. **散场情绪管理** — 防止「演唱会后忧郁症」的歌单与建议。

## 适合什么场景

- 抢到票，距离开演还有 N 天。
- 第一次去某个场馆，不熟悉动线。
- 朋友 / 家人临时陪你看演唱会，需要 30 秒科普应援。

## 注意事项

- ⚠️ 不存在的巡演会主动询问而不是编造 Setlist。

- ⚠️ 天气、最后一班车等动态信息建议现场再确认。
