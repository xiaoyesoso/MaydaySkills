# 五月天大事年表

| 年份 | 事件 |
|------|------|
| 1997 | 五月天乐队成立，前身「So Band」改组 |
| 1999 | 发行《第一张创作专辑》 |
| 2000 | 首登小巨蛋，《爱情万岁》拿下金曲奖最佳乐团 |
| 2001 | 《人生海海》发行；成员陆续入伍 |
| 2003 | 兵役归队，发行《时光机》 |
| 2004 | 《神的孩子都在跳舞》— 《倔强》成为乐队代表作 |
| 2006 | 与滚石合约结束，自立门户筹备 |
| 2007 | 与相信音乐合作，《离开地球表面》巡演 |
| 2008 | 《后青春期的诗》— 《突然好想你》拿下金曲奖最佳年度歌曲 |
| 2011 | 《第二人生》— 诺亚方舟巡演开启长达三年 |
| 2013 | 《诺亚方舟 3D 演唱会电影》上映 |
| 2016 | 《自传》— 出道 20 周年纪念 |
| 2017 | 《人生无限公司》巡演启航 |
| 2019 | 《人生无限公司》电影版上映 |
| 2022 | 疫情后回归，《好好好想见到你》巡演 |
| 2024 | 25 周年企划筹备 |
| 2025 | 《5525 回到那一天》巡演开启 |
