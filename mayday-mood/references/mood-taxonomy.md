# Mayday 情绪分类体系

> 供 `mayday-mood` Skill 调用，将自然语言情绪映射到 3 维数值标签。

## 1. 三轴定义

### 1.1 Energy（能量）
| 分数 | 描述 | 示例描述 |
|------|------|----------|
| 0-2 | 极静 | 几乎只有人声、钢琴 |
| 3-4 | 慢板 | 抒情慢歌，编曲克制 |
| 5-6 | 中速 | 流行摇滚标准 |
| 7-8 | 高能 | 大鼓 + 失真吉他 |
| 9-10 | 爆发 | 跳跃 / 全场跟唱级别 |

### 1.2 Valence（情绪极性）
| 分数 | 描述 |
|------|------|
| 0-2 | 悲伤、绝望、痛苦 |
| 3-4 | 失落、惆怅 |
| 5-6 | 中性、复杂 |
| 7-8 | 温暖、希望 |
| 9-10 | 喜悦、释放 |

### 1.3 Theme（主题枚举）
| Theme | 中文 | 触发关键词 |
|-------|------|------------|
| love | 爱情 | 喜欢、暗恋、告白、分手、想念 |
| friendship | 友情 | 朋友、兄弟、同学、毕业 |
| dream-chasing | 追梦 | 梦想、坚持、未来、努力 |
| loss | 失去 | 失恋、离别、再见、错过 |
| nostalgia | 怀旧 | 那年、青春、回忆、以前 |
| rebellion | 反抗 | 倔强、不一样、对抗、自由 |
| growth | 成长 | 长大、改变、成熟、人生 |
| celebration | 庆祝 | 派对、生日、纪念、欢乐 |

## 2. 自然语言 → 数值映射

### 2.1 关键词词典（示例）
| 用户输入 | E | V | Themes |
|----------|---|---|--------|
| 「失恋」 | 3 | 1 | loss, love |
| 「加班到崩溃」 | 4 | 2 | growth |
| 「想哭但又想被鼓励」 | 5 | 4 | growth, dream-chasing |
| 「准备打比赛」 | 9 | 8 | dream-chasing, rebellion |
| 「跟朋友重聚」 | 7 | 9 | friendship, celebration |
| 「想念家乡」 | 4 | 4 | nostalgia |
| 「失眠」 | 2 | 3 | loss, nostalgia |
| 「跑步」 | 8 | 7 | dream-chasing |

### 2.2 修饰词
- 「超级 / 非常」→ 极性 ±2
- 「有点」→ 极性 ±1
- 「又…又…」→ 取两个状态平均

## 3. 评分算法

```
score(song) = -sqrt( (E_user - E_song)^2 + (V_user - V_song)^2 )
            + 2 * |theme_overlap|
```

- 距离越小、主题重叠越多，得分越高。
- 排序后取 top-K（默认 3，最多 5）。

## 4. 输出约束

- 锚句仅引用 `lyrics_excerpt`，绝不输出全曲。
- 每首歌必须给出「为什么适合」的一句话解释。
- 若用户描述完全找不到匹配（所有距离 > 6），主动告知：「这个情绪暂时没有特别贴合的曲目，要不要换一个角度？」

## 5. 反模式

- ❌ 不要给所有失恋问题都推 《突然好想你》——这是惰性匹配。
- ❌ 不要为了凑数推荐主题完全无关的歌。
- ❌ 不要伪造未在数据库中的 mood 数值。
