# Mayday Fanfic · 五月天同人短篇

在合规边界内生成五月天宇宙的同人短篇，含红线约束和强制创作声明。

## 功能

- **同人短篇**：基于歌曲世界观、巡演幕后、AU 等场景
- **红线自检**：自动检查 R18 / 丑化真人 / 伪造引语等违规内容
- **强制声明**：每篇输出末尾自动追加创作声明

## 使用

直接对话即可，例如：
- 「写一篇《志明与春娇》多年后再相遇的短篇」
- 「五个团员上同一所大学的 AU 短篇」

详见 `references/fanfic-guidelines.md`。
