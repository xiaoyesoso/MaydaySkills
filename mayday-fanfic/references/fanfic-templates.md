# Fanfic Templates · 同人场景模板

## 1. 初遇 1997
- **场景**：大安森林公园 / 师大附中吉他社
- **适配 mood**：growth / dream-chasing
- **锚定曲**：《拥抱》
- **要素**：少年气 / 吉他 / 第一次听到自己的歌被唱出来

## 2. 兵役分别
- **场景**：2001 年暂别歌坛 / 入伍前的最后一夜
- **适配 mood**：loss / friendship
- **锚定曲**：《风若吹》
- **要素**：告别 / 不确定 / "我们会回来的"

## 3. 鸟巢之夜
- **场景**：2012 年首次北京鸟巢演唱会
- **适配 mood**：celebration / dream-chasing
- **锚定曲**：《诺亚方舟》
- **要素**：十万人 / 里程碑 / 从小酒馆到鸟巢的距离

## 4. 退役后的日常
- **场景**：假想的告别巡演之后
- **适配 mood**：nostalgia / growth
- **锚定曲**：《转眼》
- **要素**：日常感 / 回望 / 仍然在一起

## 5. 大学时代 AU
- **场景**：五人都是同一所大学的同学
- **适配 mood**：growth / friendship
- **锚定曲**：《后青春期的诗》
- **要素**：宿舍 / 乐队比赛 / 考试与梦想

## 模板结构

每个模板产出包含：
1. **开头**：场景设定（1–2 段）
2. **发展**：核心冲突或事件（2–4 段）
3. **转折**：情绪或认知变化（1–2 段）
4. **结尾**：开放或收束（1 段 + 1 句锚句致敬）
